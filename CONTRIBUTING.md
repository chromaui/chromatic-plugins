# Contributing

This repository does not accept pull requests or issues from outside
Chromatic. It is public so that agents and plugin marketplaces can install the
plugin.

- For help with the plugin, contact [Chromatic support](https://www.chromatic.com/docs/support).
- To report a security problem, see [SECURITY.md](SECURITY.md).

Chromatic engineers: the development and release guide is in the internal
Chromatic MCP Guide.
